# P2 native Integer: IR-Golden-Tests (Vorbereitung)

Die .moos-Fixture liegt unter `compiler/tests/p2/ir_native_arithmetik.moos`. `mise run p2-native-ir-golden` kompiliert sie mit dem vorhandenen Compiler nach LLVM-IR und prüft die Strukturen. `mise run p2-native-ir-check-selftest` testet ausschließlich den Shell-Checker an synthetischen IR-Zeilen. Der bestehende Python-Checker bleibt bis zum nachgewiesenen Erfolg des Ersatzes auf echtem nativem Compiler-IR erhalten und wird nicht für den neuen Ablauf benötigt.

Das Golden erwartet neun native LLVM-Funktionen mit i8-/i64-Operationen; Wrap-Operationen dürfen keine nsw/nuw-Flags tragen, Division/Rest/Shifts keine poisonversprechenden Flags. Der Checker verlangt Vergleich und bedingte Verzweigung sowie die Grenzen 0, -1, i64-MIN und 63/64 im jeweiligen Funktionskörper. Dies ist **nur ein struktureller Mindesttest**: Er beweist weder Guard-Dominanz noch die richtige Bedingung oder Kante. Semantisch gleichwertige Lowerings in anderer Form müssen nach Review im Golden ergänzt werden. Fehlende Funktionen und nicht unterstützte native Syntax schlagen fehl.

Zusätzliche verpflichtende Gates: LLVM-Verify des realen Moduls und ausführbare .moos-/C-Tests für i8-Wrap, -7/3 und -7%3, Divisor 0, i64-MIN/-1 bei Division und Rest, Shift-Counts -1/0/63/64, signed/unsigned Rechtsverschiebung, fangbare Fehler ohne Weiterlaufen, konstante Compilefehler sowie Bare-Fehlerhook. Vergleich Debug/Release und Legacy-IR bleiben eigene Gates. Die native Implementierung fehlt noch; der echte Golden-Lauf ist daher bis zur Integration nicht bestanden.
